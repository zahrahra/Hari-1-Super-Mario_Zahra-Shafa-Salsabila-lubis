5. Rangkuman Materi
   A. Prompt Engineering
      Prompt Engineering merupakan cara merancang intruksi agar AI memberikan jawaban yang tepat, relevan, dan layak untuk digunakan. Dan Prompt adalah intruksi atau              masukan yang diberikan kepada model untuk mendapatkan hasil tertentu. Dalam membuat prompt yang baik, terdapat 4 komponen utama:
     1. Role: Menentukan peran yang harus dijalankan AI.
     2. Task: Menjelaskan tugas yang harus dilakukan.
     3. Context: Memberikan informasi atau latar belakang.
     4. Format: Menentukan bentuk hasil yang digunakan.
      Semakin jelas intruksi dan konteks yang diberikan, semakin sesuai hasil yang dihasilkan AI.
  B. Pengenalan GIT
     Git adalah version control system- yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file. Git memiliiki 3 bagian utama:
    1. Working Directory: tempat penggunaan mengerjakan dan mengubah file
    2. staging Area: Tempat menyiapkan perubahan sebelum disimpan.
    3. Git Repository: Tempat menyimpan riwayat dan informasi perubahan proyek.
  C. Pengenalan Github 
      Platform berbasis web yang digunakan untuk menyimpan repository Git secara online dan mendukung kolaborasi antar pengguna.
